#  InvestigateEasy

## Feature Implemented

- **Authentication Authorization**
- **Role based access**
- **Role Switching**
- **Unified Dashboard**
- **Profile Info Update**
- **Requestor Panel**
- **Investigator Panel**


## Tech Stack

- **Framework**: React + vite
- **Language**: TypeScript
- **State Management**: React Context API
- **Styling**: Tailwind CSS with shadcn/ui components
- **Data Fetching**: Axios
- **Persistence**: LocalStorage for cart data


## Setup Instructions

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ReedwanHossain/investigate-easy-app
   cd investigate-easy-app

2. Create .env from .env.example:

```bash
  touch .env
  cp .env.example .env


   ```
3. Install Dependencies 
   ```bash
   npm install
   ``` 

4. Run application 
   ```bash
   npm run dev
   ```
INFO: Make sure you have the backend app running
